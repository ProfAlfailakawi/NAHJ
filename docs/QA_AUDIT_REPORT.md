# تقرير مراجعة الجودة الشاملة — نهج

> سجلّ حيّ يُحدَّث أثناء المراجعة. التاريخ: 2026-10-18. الفرع: `claude/full-audit-nahj`.

## 1. المنهج

- **لا وضع عرض ولا حسابات تجريبية.** كل الاختبار جرى على بياناتٍ مبذورة بنص `scripts/seed.ts`
  (`npm run seed`): حتمي، مُعاد التنفيذ، أسماء عربية واقعية، يكتب في قاعدة التطوير نفسها (`var/nahj.sqlite`).
- **الأدوار المختبَرة:** مالك المنصة (owner)، مشرف المؤسسة (admin)، مدير (manager)، مشغّل (operator)،
  مُطّلع (viewer)، مسوّق (partner) — على سطح المكتب (1366px) والهاتف (390px)، بالعربية والإنجليزية.
- **ما فُحص:** كل قسم في الواجهة (17 قسماً)، مصفوفة صلاحيات كل مسار API لكل دور، عشوائية المدخلات
  (888 طلباً مشوَّهاً على كل مسارات الكتابة، صفر أخطاء 5xx)، انتهاء الجلسة، الضغط المزدوج،
  القوائم الكبيرة، حالة المؤسسة الفارغة (أول تشغيل: تهيئة ← إعداد المؤسسة ← الأقسام كلها)، القراءة النقدية للخادم.
- **خط الأساس قبل أي تعديل:** `npm run lint` نظيف، `npm test` 286/286، `npm run build` ناجح.

## 5. غير المحلول / غير المتحقَّق منه (بصدق)

- **حدود الباقة غير المفروضة:** المفروض فعلاً حدّ المقاعد وسقف الاستقلالية فقط (موثَّق في `BILLING.md`)؛ أما المهارات والموصلات وحالات الشهر ونداءات الذكاء فتُعرض وتُقاس ولا تُمنع. قرارٌ تجاري للمالك.
- **التحصيل الإلكتروني والبريد والذكاء الاصطناعي الحقيقية:** لا اعتماديات متاحة هنا، فلم تُجرَّب بوابة ماي فاتورة/تاب ولا مزوّد البريد ولا مفتاح Gemini (ومعرّف النموذج `gemini-3.8-flash` لم أستطع التحقق منه). فُحصت مسارات الفشل فقط (بلا بوابة، مهلة، رفض). **يلزم اختبار بوابة الدفع في وضع الاختبار قبل أول فاتورة.**
- **وضع العرض (demo):** تُرك كما هو بلا مسّ (لا حذف لميزة)، ولم يُستعمل في أي اختبار هنا. الإعداد الافتراضي له `NAHJ_DEMO_ENABLED=true`؛ اضبطه `false` في نشرٍ حقيقي إن لم تُرد إظهار بوابته.
- **المحادثة التجريبية (المحاكي) وجلسة التعليم عامّتان للمؤسسة:** محادثةٌ واحدة مشتركة لكل الموظفين؛ موظفان يجرّبان معاً يُربكان بعضهما. تصميمٌ قائم لم أغيّره.
- **أوقات «الآن» في الخط الزمني** نصوصٌ ثابتة لا تشيخ (تصميمٌ قائم)؛ سجلّ التدقيق نفسه يحمل طابعاً حقيقياً.
- **خوادم MCP المسجَّلة تُفقد عند إعادة التشغيل** (في الذاكرة)؛ ولا واجهة لها اليوم (API فقط).
- **القفل بعد 8 محاولات فاشلة** يستطيع أي شخصٍ يعرف بريداً أن يقفل صاحبه 15 دقيقة (مقايضةٌ مقبولة، ويحميها حدّ IP).
- لم تُختبر متصفحاتٌ غير Chromium، ولا أجهزة حقيقية، ولا قارئ شاشة فعلي، ولا Lighthouse.
- الحفظ الدوري كل 3 ثوانٍ: انقطاعٌ مفاجئ للكهرباء قد يفقد آخر ثوانٍ (الإيقاف النظيف يحفظ).
- تسجيل 300 دخولٍ متزامن استغرق ~12 ثانية (كلفة scrypt المقصودة)؛ لا تسجيل ذاتي فلا ذروة دخولٍ واقعية بهذا الحجم.
